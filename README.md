# Сканер PDF

Бесплатный сканер документов для Android: без рекламы, без водяных знаков, без аккаунтов и без интернета.

## Что умеет

- Снимок системной камерой или фото из галереи (можно сразу несколько).
- Автоматический поиск краёв листа и ручная правка уголков с лупой.
- Выравнивание перспективы: лист, снятый под углом, становится ровным прямоугольником.
- Фильтры «Улучшить» (убирает тени и желтизну, цвет печатей остаётся), «Серый», «Ч/Б» и «Оригинал», с живыми миниатюрами.
- Многостраничные документы: добавить, повернуть, переставить и удалить страницу.
- Экспорт в PDF и JPG: «Поделиться» в любое приложение или сохранение в «Файлы».
- Светлая и тёмная тема.

Чего нет намеренно: разрешений (камера и галерея открываются системными окнами), интернета, рекламы, аналитики. Документы лежат только в памяти приложения и не попадают в облачные резервные копии.

## Устройство

- `core` — чистый Kotlin без Android, покрыт тестами (`./gradlew :core:test`):
  - `EdgeDetector` — поиск листа: уменьшение, морфологическое закрытие (убирает строки текста), Собель, преобразование Хафа и перебор четырёхугольников по качеству краёв и площади. Без OpenCV, поэтому APK маленький.
  - `Filters` — выравнивание освещения по яркости бумаги и адаптивный порог Брэдли для ч/б.
  - `PdfWriter` — PDF, в котором страницы лежат готовыми JPEG; файл в разы меньше, чем через `PdfDocument`.
- `app` — Android на Jetpack Compose: хранение документов (`data/Docs.kt`, JSON и JPEG в папке приложения), обработка (`scan/Scanner.kt`, перспектива через `Matrix.setPolyToPoly`), экраны (`ui/`).
- minSdk 24 (Android 7), targetSdk 35, без Google Play Services, работает и на Huawei.

Тестовые фото в `core/src/test/resources/photos` сгенерированы скриптом, это не реальные документы.

## Сборка

```
./gradlew :core:test assembleDebug
```

Нужны JDK 17 и Android SDK. GitHub Actions собирает APK при каждом изменении (артефакт `skaner-apk`) и снимает скриншоты в эмуляторе (артефакт `screenshots` и ветка `checks/screenshots`).

### Подпись для RuStore

В настройках репозитория (Settings → Secrets and variables → Actions) добавить секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. После этого в артефакте появится подписанный `app-release.apk`.
